RoboSoccer Tournament Manager Website

Languages used:

  • PHP
  • HTML
  • TailWind
  • SQL

    What this project taught me:
    This project focused on building a web platform for managing RoboSoccer tournaments, including features such as team registration, match scheduling, and result tracking. Working on this project helped me improve my skills in full-stack web development, database design, and responsive UI implementation. I also gained experience in managing user authentication, applying coding standards, and deploying applications. The project challenged me to think critically about usability, maintainability, and scalability, all while ensuring a seamless experience for both administrators and participants. I also learned how to apply in a project the agile method "SCRUM", which helped all the team work way more efficiently and pushed us to help eachother.
